**1. THE BASIC ANATOMY OF AN HTML DOCUMENT 📑

Every HTML file must follow a specific structure so that browsers like Chrome or Firefox can read it correctly.**

The Boilerplate Code 🧱

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>My HTML Masterpiece 🌸</title>
</head>
<body>
    <h1>Hello World! Welcome to my Journey! 🚀</h1>
</body>
</html>

Breakdown of Components 🔍

    <!DOCTYPE html>: This tells the browser that we are using HTML5, the latest version. 📜

    <html>: The "Root" element. Everything starts and ends here. 🌍

    <head>: This is the "Brain" of the page. It contains info that doesn't show up on the screen, like the title and links to CSS. 🧠

    <body>: The "Heart" of the page. Everything you see—text, images, buttons—lives here. ❤️

    3. TEXT CONTENT & FORMATTING ✍️

To make your text readable and engaging, use these tags:
Paragraphs & Breaks 🌊

    <p>: Used for long blocks of text. 🖋️

    <br>: A line break to jump to the next line without starting a new paragraph. ↩️

    <hr>: A horizontal rule to separate sections with a line. ➖

Text Emphasis ✨

    <strong> or <b>: Makes text BOLD. Use <strong> for importance. 💪

    <em> or <i>: Makes text ITALIC. Use <em> for emphasis. 🤌

    <mark>: Highlights text in yellow, just like a highlighter pen! 🖍️

    <u>: Underlines the text. 🖋️

🔗 4. HYPERLINKS & NAVIGATION 🚢

The internet is a web of links. The <a> (Anchor) tag is how we travel!

    External Link: <a href="[https://google.com](https://google.com)">Visit Google</a> 🌐

    Open in New Tab: Use target="_blank" so the user doesn't leave your site. 📂

    Internal Link: Link to another page in your folder like about.html. 📁

🖼️ 5. IMAGES & MULTIMEDIA 🎨

A website without pictures is boring! Use the <img> tag.

    src: The path to your image file. 📍

    alt: Description of the image (Great for blind users and Google SEO). 🗣️

    width & height: To control the size. 📏

📋 6. LISTS: STAYING ORGANIZED ✨

As a Virtual University student, you know how important lists are for study schedules!
Unordered List (Bullets) 🔴

    Use <ul> as the parent.

    Use <li> for each item.

    Perfect for: Hobbies, Skills, Features.

Ordered List (Numbers) 🔢

    Use <ol> as the parent.

    Perfect for: Recipe steps, Top 10 lists, Step-by-step logic.

📊 7. TABLES: DISPLAYING DATA 🗄️

Tables are used to show structured data like your CS201 Lecture Schedule.

    <table>: The main wrapper. 📦

    <tr>: Table Row. 🚣

    <th>: Table Header (Bold and centered). 🧢

    <td>: Table Data (Normal cell). 📑

📥 8. FORMS: USER INTERACTION 📨

Forms are used to collect data, like Login or Sign-up pages.

    <input type="text">: For names. 👤

    <input type="password">: For secret keys. 🔑

    <input type="email">: For contact info. 📧

    <button>: The "Submit" action. 🖱️

    <textarea>: For long messages/comments. 💬

📦 9. CONTAINERS: DIVS & SPANS 🏗️

    <div>: A Block-level element. It takes up the whole width. It is a big box used to group sections together. 🧱

    <span>: An Inline element. It only takes as much space as it needs. Used for styling specific words inside a sentence. 🤏

    🛠️ CHAPTER 10: GLOBAL ATTRIBUTES & SEO 🚀

Attributes give tags extra "powers."

    id: A unique name for a tag (Only one per page!). 🆔

    class: A name for a group of tags (Many tags can share one class). 👥

    title: Shows a "tooltip" when you hover your mouse. 🖱️

    style: To add CSS directly (Inline styling). 🖌️

    lang: Important for Google to know what language you are using. 🗣️

    CHAPTER 11: DATA STRUCTURES (TABLES & LISTS) 📊
    
Complex Tables 🗄️

Tables aren't just rows; they have a header (<thead>), a body (<tbody>), and a footer (<tfoot>).

    colspan: To merge columns. 🤝

    rowspan: To merge rows. 🪜

4.2 Nested Lists 🌳

You can put a list inside another list! This is great for creating multi-level menus or complex study plans.

🏆 12. HTML BEST PRACTICES FOR BEGINNERS 🥇

    Always Close Your Tags: If you open <div>, you must close it with </div>. 🚪

    Use Indentation: Keep your code clean so it's easy to read (like your C++ code!). 🧹

    Use Lowercase: Keep all tags in lowercase (e.g., <body> not <BODY>). 🔡

    Alt Text: Never forget alt for your images! 🖼️
